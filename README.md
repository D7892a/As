# نظام الكاشير العراقي — إدارة المطاعم 🍽️

نظام نقاط بيع (POS) متكامل لإدارة المطاعم، يعمل بالكامل في المتصفح بدون سيرفر — البيانات محفوظة محلياً في `localStorage`.

## 🚀 التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8080
```

### حسابات الدخول الافتراضية

| المستخدم | الدور | الرمز السري |
|---|---|---|
| مدير النظام | admin | `1234` |
| أحمد الكاشير | cashier | `1111` |

---

## 🔐 المستخدمون والصلاحيات

- تسجيل دخول متعدد المستخدمين بشاشة اختيار المستخدم + لوحة رمز سري (PIN).
- أربعة أدوار جاهزة: **مدير النظام**، **مدير مناوب**، **كاشير**، **مطبخ**.
- **21 صلاحية دقيقة** يمكن منحها أو سحبها لكل موظف على حدة من محرّر الصلاحيات
  (منح الخصومات، تعديل السعر عند البيع، إلغاء/حذف الطلبات، إدارة الوجبات، المخزون، التقارير، التصفير...).
- الصفحات والأزرار تختفي تلقائياً لمن لا يملك صلاحيتها، مع حماية على مستوى الدوال أيضاً.
- الجلسة محفوظة، ولا يمكن حذف آخر حساب مدير في النظام.

## 🛠️ أدوات المدير (التصفير)

صفحة مخصّصة للمدير — كل عملية محميّة بتأكيد **رمز المدير** ولا يمكن التراجع عنها:

- تصفير **جميع الطلبات** (مع خيار إعادة عدّاد الأرقام)، حذف طلبات اليوم فقط، تنظيف الطلبات الملغاة.
- ضبط عدّاد أرقام الطلبات من رقم مُحدَّد.
- تصفير **جميع الوجبات**، تصفير الأقسام، أو استعادة القائمة العراقية الافتراضية.
- تصفير العروض، المخزون، العملاء، نقاط الولاء، المصروفات، الورديات.
- إعادة ضبط المصنع + نسخة احتياطية JSON قبل التصفير.
- **سجل نشاط** يوثّق كل عملية (من نفّذها ومتى).

## 🆕 الأقسام الجديدة

| القسم | الوصف |
|---|---|
| 🔥 **العروض** | وجبات مركّبة بسعر مخفّض، مع احتساب نسبة التوفير، شارة تسويقية، تواريخ سريان وأيام محددة، وتظهر كشريحة خاصة داخل نقطة البيع. |
| 🪑 **الطاولات** | خريطة صالة بالمناطق وحالات (متاحة / مشغولة / محجوزة / تنظيف)، ربط الطلب بالطاولة وتحريرها تلقائياً عند الإكمال. |
| 🔥 **شاشة المطبخ (KDS)** | لوحة ثلاثية الأعمدة بتحديث تلقائي كل 15 ثانية، مؤقّت لكل طلب وتنبيه بصري للطلبات المتأخرة. |
| 📦 **المخزون** | كميات وتكلفة لكل صنف، خصم تلقائي عند البيع وإرجاع عند الإلغاء، تنبيه نقص المخزون، جرد سريع وتقرير قيمة المخزون. |
| 💸 **المصروفات** | تسجيل المصروفات بتصنيفات، رسم توزيع بياني، واحتساب **صافي الربح**. |
| 🔒 **الورديات** | فتح وردية برصيد افتتاحي، تقفيل الصندوق مع مقارنة المتوقع بالفعلي، وطباعة **تقرير Z** مفصّل. |
| 👥 **المستخدمون** | إدارة فريق العمل والأدوار والصلاحيات. |
| 🛡️ **أدوات المدير** | مركز التصفير والصيانة وسجل النشاط. |

## 📁 بنية المشروع

```
index.html
css/styles.css
js/
├── db.js          طبقة البيانات، الترقية التلقائية، وعمليات CRUD والتصفير
├── auth.js        الأدوار والصلاحيات وشاشة الدخول وحماية العمليات
├── ui.js          التنقل، الإشعارات، النوافذ، وأدوات الواجهة
├── pos.js         نقطة البيع والسلة والدفع
├── sections.js    الطلبات، الوجبات، الأقسام، المبيعات، العملاء
├── offers.js      العروض والوجبات المركّبة
├── tables.js      الطاولات
├── kitchen.js     شاشة المطبخ
├── finance.js     المصروفات والورديات وتقرير Z
├── inventory.js   المخزون والجرد
├── users.js       المستخدمون ومحرّر الصلاحيات
├── admin.js       أدوات المدير والتصفير وسجل النشاط
├── reports.js     التقارير والرسوم البيانية
└── settings.js    الإعدادات والطباعة وتصدير PDF
```

> جميع البيانات تُحفظ محلياً في متصفح الجهاز — استخدم زر النسخة الاحتياطية (JSON) قبل أي عملية تصفير.
