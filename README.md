# نظام الكاشير العراقي — إدارة المطاعم 🍽️

نظام نقاط بيع (POS) متكامل لإدارة المطاعم، يعمل بالكامل في المتصفح بدون سيرفر — البيانات محفوظة محلياً في `localStorage`.

## 🚀 التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8080
```

### حسابات الدخول الافتراضية

| المستخدم | الدور | الرمز السري |
|---|---|---|
| مدير النظام | admin | `1234` |
| أحمد الكاشير | cashier | `1111` |

## 🔐 المستخدمون والصلاحيات

- تسجيل دخول متعدد المستخدمين بشاشة اختيار المستخدم + لوحة رمز سري (PIN).
- أربعة أدوار جاهزة: **مدير النظام**، **مدير مناوب**، **كاشير**، **مطبخ**.
- **21 صلاحية دقيقة** يمكن منحها أو سحبها لكل موظف على حدة من محرّر الصلاحيات
  (منح الخصومات، تعديل السعر عند البيع، إلغاء/حذف الطلبات، إدارة الوجبات، المخزون، التقارير، التصفير...).
- الصفحات والأزرار تختفي تلقائياً لمن لا يملك صلاحيتها، مع حماية على مستوى الدوال أيضاً.
- الجلسة محفوظة، ولا يمكن حذف آخر حساب مدير في النظام.

## 🛠️ أدوات المدير (التصفير)

صفحة مخصّصة للمدير — كل عملية محميّة بتأكيد **رمز المدير** ولا يمكن التراجع عنها:

- تصفير **جميع الطلبات** (مع خيار إعادة عدّاد الأرقام)، حذف طلبات اليوم فقط، تنظيف الطلبات الملغاة.
- ضبط عدّاد أرقام الطلبات من رقم مُحدَّد.
- تصفير **جميع الوجبات**، تصفير الأقسام، أو استعادة القائمة العراقية الافتراضية.
- تصفير العروض، المخزون، العملاء، نقاط الولاء، المصروفات، الورديات.
- إعادة ضبط المصنع + نسخة احتياطية JSON قبل التصفير.
- **سجل نشاط** يوثّق كل عملية (من نفّذها ومتى).

## ⚡️ الجديد في الإصدار 2 — تطوير ضخم

### 🧭 لوحة القيادة (الصفحة الرئيسية الجديدة)
- مؤشرات لحظية: إيراد اليوم مع **نسبة النمو مقابل الأمس**، عدد الطلبات، متوسط الفاتورة.
- **صافي الربح اليومي** محسوباً آلياً (الإيراد − كلفة البضاعة المباعة − المصروفات) مع نسبة الهامش.
- **شريط تنبيهات ذكي** قابل للنقر: وردية غير مفتوحة، أصناف قاربت على النفاد، طلبات توصيل جارية، حجوزات اليوم، ذمم الموردين.
- رسم مزدوج (إيراد + عدد طلبات) لآخر 7 / 14 / 30 يوماً، ورسم **ذروة المبيعات حسب الساعة** مع تمييز ساعة الذروة.
- مؤشرات تشغيلية بأشرطة تقدّم: إشغال الصالة، التوصيل الجاري، الحجوزات، أصناف تحتاج تزويد، حالة الوردية.

### 🚚 التوصيل (الدليفري)
- **إنشاء سجل توصيل تلقائياً** عند إتمام أي طلب من نوع «توصيل» في نقطة البيع.
- دورة حياة كاملة: بانتظار سائق → مُسند → في الطريق → تم التسليم (مع إكمال الطلب آلياً).
- **إنذار التأخير**: بطاقة الطلب تنبض بالأحمر إذا تجاوز الزمن المتوقع لمنطقته.
- إدارة **السائقين**: مركبة، رقم لوحة، عمولة لكل طلب، حالة نشط/موقوف، وإحصاء الطلبات المُسلّمة والأجور.
- إدارة **مناطق التوصيل**: أجرة وزمن متوقع لكل منطقة — تُطبَّق الأجرة آلياً على فاتورة نقطة البيع.
- تقرير أداء التوصيل تفصيلياً حسب السائق (مبيعات، أجور، مستحق العمولة).

### 📅 الحجوزات
- حجز الطاولات مسبقاً بالتاريخ والوقت وعدد الضيوف والعربون.
- **مزامنة تلقائية مع الطاولات**: الطاولة تصبح «محجوزة» ثم «مشغولة» عند وصول الضيوف وتتحرر عند الإنهاء.
- حالات: محجوز / جالس الآن / مكتمل / لم يحضر / ملغي — مع نسبة عدم الحضور.
- خط زمني مرتّب حسب الساعة + طباعة قائمة حجوزات اليوم.

### 🏭 الموردون والمشتريات
- **فواتير شراء** بأصناف متعددة، تُضاف كمياتها للمخزون وتُحدّث تكلفة الصنف تلقائياً.
- **ذمم الموردين**: رصيد مستحق لكل مورد يتناقص مع كل دفعة، وحالات (مسددة / جزئية / غير مسددة).
- بطاقات موردين بالتصنيف والشخص المسؤول وسجل الفواتير، وتقرير مشتريات وذمم قابل للطباعة.

### 💼 الرواتب والهدر
- **كشف رواتب شهري**: أساسي + مكافآت − استقطاعات − سلف = الصافي، مع توليد تلقائي لكل الموظفين.
- صرف الراتب **يُسجَّل تلقائياً كمصروف** في قسم المصروفات.
- **سجل الهدر والتالف** بأسباب (تالف، انتهاء صلاحية، خطأ تحضير، إرجاع...) — يخصم الكمية من المخزون ويحسب الكلفة.

### 📱 المنيو الرقمي QR والتقييمات
- توليد **رمز QR** للمنيو + بطاقة طاولة جاهزة للطباعة.
- معاينة حيّة للمنيو داخل إطار هاتف كما يراه الزبون + طباعة المنيو الكامل.
- **تقييمات العملاء**: طعام / خدمة / سرعة، توزيع بياني للنجوم، وسجل الآراء.

### 🏅 مستويات ولاء العملاء
- أربعة مستويات آلية حسب إجمالي الإنفاق: 🥉 برونزي • 🥈 فضي • 🥇 ذهبي • 💎 VIP.
- **خصم تلقائي** يُطبَّق على فاتورة نقطة البيع حسب مستوى العميل، وشارة المستوى تظهر في السلة وجدول العملاء.
- حدود المستويات ونسب الخصم قابلة للضبط بالكامل من الإعدادات.

### 🔎 أدوات القوة
- **لوحة الأوامر والبحث الشامل** (`Ctrl + K`): ابحث عن صفحة، منتج، طلب، عميل، أو سائق — ونفّذ أوامر مباشرة مع تنقّل بالأسهم.
- **اختصارات لوحة المفاتيح**: `F1` نقطة البيع • `F2` الطلبات • `F3` الطاولات • `F4` المطبخ • `F5` لوحة القيادة • `F8` التوصيل • `F9` الدفع • `Ctrl+D` وضع ليلي • `Ctrl+B` نسخة احتياطية • `Ctrl+P` طباعة آخر إيصال • `؟` عرض الاختصارات.
- **🌙 وضع ليلي كامل** يشمل كل الصفحات ويُحفظ بين الجلسات.
- **نسخ احتياطي تلقائي** كل دقيقتين مع إمكانية الاسترجاع بضغطة، ومؤشر لحجم التخزين المستخدم.
- **تصدير CSV/Excel** للطلبات والوجبات والعملاء (بترميز عربي سليم).
- **PWA**: يعمل بالكامل **بدون إنترنت** ويمكن تثبيته كتطبيق على الموبايل والحاسوب.

## 🆕 الأقسام السابقة

| القسم | الوصف |
|---|---|
| 🔥 **العروض** | وجبات مركّبة بسعر مخفّض، مع احتساب نسبة التوفير، شارة تسويقية، تواريخ سريان وأيام محددة، وتظهر كشريحة خاصة داخل نقطة البيع. |
| 🪑 **الطاولات** | خريطة صالة بالمناطق وحالات (متاحة / مشغولة / محجوزة / تنظيف)، ربط الطلب بالطاولة وتحريرها تلقائياً عند الإكمال. |
| 🔥 **شاشة المطبخ (KDS)** | لوحة ثلاثية الأعمدة بتحديث تلقائي كل 15 ثانية، مؤقّت لكل طلب وتنبيه بصري للطلبات المتأخرة. |
| 📦 **المخزون** | كميات وتكلفة لكل صنف، خصم تلقائي عند البيع وإرجاع عند الإلغاء، تنبيه نقص المخزون، جرد سريع وتقرير قيمة المخزون. |
| 💸 **المصروفات** | تسجيل المصروفات بتصنيفات، رسم توزيع بياني، واحتساب **صافي الربح**. |
| 🔒 **الورديات** | فتح وردية برصيد افتتاحي، تقفيل الصندوق مع مقارنة المتوقع بالفعلي، وطباعة **تقرير Z** مفصّل. |
| 👥 **المستخدمون** | إدارة فريق العمل والأدوار والصلاحيات. |
| 🛡️ **أدوات المدير** | مركز التصفير والصيانة وسجل النشاط. |

## 📱 التثبيت كتطبيق (PWA)

شغّل النظام عبر خادم محلي (وليس بفتح الملف مباشرة) ثم:
- **على الموبايل**: من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية».
- **على الحاسوب**: اضغط أيقونة التثبيت في شريط العنوان.

بعد التثبيت يعمل النظام **بدون إنترنت بالكامل**.

## 🔐 الصلاحيات

ارتفع عدد الصلاحيات إلى **29 صلاحية دقيقة** بإضافة: لوحة القيادة، التوصيل، الحجوزات، الموردون والمشتريات، الرواتب، سجل الهدر، والمنيو الرقمي — كل واحدة تُمنح أو تُسحب لكل موظف على حدة.

> جميع البيانات تُحفظ محلياً في متصفح الجهاز — استخدم زر النسخة الاحتياطية (JSON) قبل أي عملية تصفير.
